次の発言に答えるのに、web を引く必要があるか判断して。

発言:
{{問いかけ}}

引く必要があるのは、たとえばこういうとき:

- 最新の情報・バージョン・リリース・ニュースが要る
- 固有名詞 (ライブラリ、製品、人、出来事) について事実を説明する必要がある
- 「教えて」「解説して」「とは」「どうなってる」と中身を求められている
- 手元の知識だけだと古い可能性がある

引かなくてよいのは、たとえばこういうとき:

- 挨拶、相槌、雑談、感想、冗談
- 相手や自分自身についてのやりとり
- 意見や好みを訊かれているだけ
- すでに会話の中で答えが出ている

2 行だけで答えて。前置きも説明もしない。

調べる: <はい / いいえ>
検索語: <引くなら検索に入れる語。引かないなら空>

「検索語」は**検索窓に打ち込む語**であって、発言をそのまま写すところではない。
「〜について教えて」「〜って何」のような頼み方の言い回しは落とし、調べる対象そのものだけを残す。固有名詞はそのまま。5 語まで。

例:

- 「ryoppippi について教えて」 → `調べる: はい` / `検索語: ryoppippi`
- 「Vue の Vapor Mode ってどうなった」 → `調べる: はい` / `検索語: Vue Vapor Mode`
- 「おはよう」 → `調べる: いいえ` / `検索語:`
